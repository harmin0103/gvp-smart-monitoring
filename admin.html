Demo Settings & About

System scope, assumptions and demonstration controls.

GVP Watch — Smart Waste Monitoring

A concept dashboard for the problem statement PS000058 submitted for Gandhidham Municipal Corporation. The proposed solution combines CCTV video analytics, detection of suspicious vehicle halts and dumping activity, and Automatic Number Plate Recognition (ANPR) to support faster municipal response.

Prototype capabilities

  • Monitoring dashboard with sample operational KPIs
  • Simulated CCTV preview panels
  • Sample GVP hotspot register and risk levels
  • Incident review table with status updates
  • Fictional ANPR vehicle records
  • CSV export for demonstration data
Important demo disclaimer: This is a front-end demonstration only. It does not connect to live CCTV, run a computer-vision model, verify number plates, issue legal fines, or store data in a database. All incidents, plates, locations and metrics are fictional sample data. Any real enforcement action would require human verification and an authorized municipal workflow.
